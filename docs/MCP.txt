1. The "Stealth" Browser (Anti-Bot Evasion)
Most big websites (Amazon, Flipkart, Moneycontrol) use "Bouncers" (like Cloudflare or DataDome) to spot automated scripts. Firecrawl bypasses these by using Managed Headless Browsers equipped with stealth plugins.
Fingerprint Randomization: Every time Firecrawl visits a site for you, it mimics a different device—changing its screen resolution, user-agent, and hardware signatures so it looks like a real human on a MacBook or an Android phone.
Behavioral Mimicry: It doesn't just "hit" a URL. It mimics human micro-actions like scrolling, moving the mouse naturally, and waiting a few seconds before "reading" the data.
CAPTCHA Solving: If a site throws a "Prove you are human" puzzle, Firecrawl has built-in AI solvers that crack reCAPTCHAs and hCaptchas in the background before you even see the data.

2. The "Chameleon" Network (Proxy Rotation)
If you tried to scrape 100 prices from your home IP, Amazon would block you in minutes. Firecrawl uses a massive Global Proxy Pool:
Residential Proxies: It routes your request through "Residential IPs"—addresses that look like they belong to a standard home internet user in Mumbai or New York.
Automatic Rotation: For every request in your Astra cron, it uses a fresh IP. To the website, it looks like 1,000 different people are looking at the price, not one bot.

3. The "Semantic" Brain (LLM Extraction)
This is the "magic" part you saw in your logs. Traditional scrapers rely on CSS Selectors (e.g., find the text inside <span id="price">). If the website changes its code even slightly, the scraper breaks.
Firecrawl uses "LLM Extraction" (powered by their Spark model family):
Contextual Understanding: It doesn't just look for a code tag; it "looks" at the page like a human. It understands that a large number next to a currency symbol near the product title is likely the "Selling Price."
Schema Mapping: Because you gave it a JSON schema, it performs a semantic search. Even if the price is hidden in a weird pop-up or a dynamic JavaScript element, the internal LLM finds it and maps it to your price key.
